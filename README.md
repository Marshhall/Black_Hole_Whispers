# Black Hole Whispers

Exploring what gravitational waves reveal about merging black holes through Bayesian inference and Metropolis sampling.

The project starts with parameter estimation from noisy synthetic data, then applies the same methods to LIGO observations of **GW150914**, the first directly detected gravitational-wave event.

## Objectives

- Implement a Metropolis sampler for Bayesian parameter estimation.
- Explore how priors and measurement noise affect posterior distributions.
- Estimate a common black-hole component mass and a distance parameter using a simplified waveform model.
- Visualize posterior distributions and compare inferred waveforms with detector data.
